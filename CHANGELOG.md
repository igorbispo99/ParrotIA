# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Fixed
- Match GNOME's launcher to Tk's actual window class so the running Snap groups
  under its existing icon, and follow the desktop portal's dark/light preference.
- Ship one Snap desktop launcher, removing the duplicate generated by declaring
  both a packaged launcher and an app-level desktop file.
- Configure bundled Snap text and shape fonts independently of the host desktop,
  use software font drawing for virtualized XWayland displays, and verify
  visible glyphs at normal and high DPI during package QA.

## [1.5.3] - 2026-11-17

### Fixed
- Keep the macOS GUI responsive during native model loading, language detection,
  and transcription by running inference in a managed child process.
- Cancel and reap inference workers before closing the window, including Command-Q;
  release cached Metal models explicitly before shutdown and model replacement.
- Allow cancellation to recover from unresponsive native work and restart a failed
  inference worker for the next job.
- Release native models after CLI transcription and benchmarking; support using
  `Transcriber` as a context manager for library callers.

### Added
- Native Linux ARM64 desktop installers (DEB and RPM), with architecture-specific
  build, installation checks, and release downloads alongside x86-64.
- ARM64 Snap Store distribution, with hash-pinned dependencies, native CI
  package QA, signed delivery verification, and portable runtime library discovery.
- Frozen macOS GUI checks with a real tiny model: complete transcription, quit
  during decoding, GUI responsiveness, and worker cleanup on both architectures.

## [1.5.2] - 2026-11-16

### Added
- macOS installers for Apple Silicon and Intel, with Python and media codecs included.
- Automatic Metal acceleration on Apple Silicon, with CPU fallback and an explicit CPU option.
- Homebrew cask distribution with architecture-specific installer checksums.

### Fixed
- Statically link the macOS whisper.cpp runtime so frozen apps include all
  required native code, with an import check before packaging.
- Select an explicit build architecture and use faster-whisper for Intel
  Python installations to avoid broken upstream source wheels.

## [1.5.1] - 2026-11-16

### Fixed
- Include the macOS PyInstaller spec in Git checkouts and source distributions.
- Simulate the macOS data directory independently of the test host OS.

### Added
- Generate a Homebrew cask with architecture-specific SHA-256 checksums from
  the release DMGs.

## [1.5.0] - 2026-11-16 (unpublished)

### Added
- macOS app bundles and drag-to-Applications DMGs for Apple Silicon and Intel,
  with build/install smoke checks, release artifacts, and optional Developer ID
  signing and notarization.
- Automatic whisper.cpp selection on macOS, Metal acceleration on Apple Silicon,
  explicit CPU/Metal device control, and CPU fallback for automatic Metal loading.
- Bundled PyAV media decoding and CA certificates on macOS, plus a native model
  cache under `~/Library/Application Support/parrotia/models`.

### Fixed
- Probe GUI availability in a separate process so macOS Tk is not initialized
  and destroyed before the GUI tests start.

## [1.4.1] - 2026-11-16

### Changed
- Allow CustomTkinter 6 (`customtkinter>=5.2.2,<7`). The GUI and its tests
  pass unchanged on 6.0.0, the version proposed for Fedora.

## [1.4.0] - 2026-11-13

### Added
- whisper.cpp inference backend (through `pywhispercpp`), selected automatically
  when faster-whisper is not installed, or with `--backend whisper.cpp` /
  `PARROTIA_BACKEND`. It lets distributions without CTranslate2, such as Fedora,
  ship ParrotIA from source. Its model downloads are pinned to exact Hugging Face
  revisions, verified by SHA-256, written atomically and resumable, and can be
  placed with `PARROTIA_MODELS_DIR`.
- Freedesktop desktop entry, hicolor icon and AppStream MetaInfo under the
  application ID `io.github.igorbispo99.ParrotIA`. The GUI sets a matching
  window class so desktops associate the window with its launcher.
- Native Fedora RPM specs for ParrotIA and its unpackaged dependencies
  (`python-customtkinter`, `python-darkdetect`) in `packaging/fedora/`.

### Fixed
- GUI tests no longer turn every window construction error into a skip; only
  display/Tk failures skip.

### Changed
- Package metadata uses an SPDX license expression (`license-files`), which
  needs setuptools 77 or newer to build.

## [1.3.1] - 2026-11-11

### Fixed
- The "Downloading model... first time setup" notice no longer appears on every
  run with the `large-v3-turbo` model. The cache check used the wrong
  HuggingFace repository (`Systran/...` instead of `mobiuslabsgmbh/...`), so an
  already downloaded model was never detected.

## [1.3.0] - 2026-11-11

### Added
- Self-contained Windows x64 installer with a per-user setup wizard, desktop and
  Start menu shortcuts, a branded parrot icon, and clean Explorer unregistration
  on uninstall. Python and FFmpeg do not need separate installation.
- Self-contained Linux x86-64 `.deb` and `.rpm` installers with application-menu
  entries and a parrot icon. Package checks install, run, and uninstall the app in
  Ubuntu and in a clean Fedora container before release.
- **Transcribe on Parrot** Explorer action for supported audio/video extensions,
  including multiple selections collected into a single sequential queue and
  progress window. UTF-8 text saves beside each source without overwriting
  existing files. Per-file failures and cancellation are supported.
- Platform build scripts, shared PyInstaller packaging, frozen-app smoke tests
  (audio decoding, ONNX, Tk), and `.exe` / `.deb` / `.rpm` artifacts on releases.
- Regression tests for Explorer request concurrency, process ownership,
  collision-safe filenames, cancellation, and resilient batch processing.

### Changed
- Packaged GUI windows use the same parrot icon as the installer and shortcuts.
- Dependency constraints keep PyAV compatible with faster-whisper's audio
  decoder and retain CustomTkinter 5 for the existing GUI.
- The GUI uses its packaged parrot image and text labels instead of decorative
  color emojis, avoiding crashes in older Linux Tk/font combinations.

## [1.2.0] - 2026-06-08

### Added
- Model download detection: `Transcriber.is_model_cached()` checks the local
  HuggingFace cache so the app can tell whether a model needs to be downloaded.
- `MODEL_SIZES` and `_MODEL_REPOS` constants mapping each model name to its
  approximate download size and HuggingFace repo ID.
- GUI shows an indeterminate progress bar with a descriptive "📥 Downloading…"
  status message during first-time model downloads; switches to normal
  determinate progress once loading begins.
- Full pytest test suite (`tests/`) covering transcriber, formats, CLI,
  benchmark, public API surface, and GUI (auto-skipped on headless CI).
- CI workflow (`.github/workflows/ci.yml`) running tests on Python 3.9–3.12
  across Linux, Windows, and macOS, plus ruff lint/format checks and a wheel
  install smoke-test.
- `[dev]` optional dependency group (`pytest`, `pytest-cov`) in `pyproject.toml`.
- pytest configuration block in `pyproject.toml` (`[tool.pytest.ini_options]`).

### Changed
- Release workflow now delegates build, test, and lint to the reusable CI
  workflow instead of an inline build job, ensuring no release ships without
  passing CI.

## [1.1.0] - 2026-06-06

### Changed
- Reskinned the GUI with a parrot-themed visual identity drawn from the project
  banner: a branded "ParrotIA" hero header with logo, two-tone wordmark and
  feature badges (Offline / No Internet / Fast & Easy / Powered by Whisper).
- Sections are now rounded cards with emoji headings, and controls use a
  cohesive palette (green primary action, blue inputs, coral cancel, teal
  accents) that adapts to light and dark mode.

### Added
- Optional PyPI publishing job in the release workflow (via Trusted Publishing).

## [1.0.0] - 2026-06-05

First packaged release.

### Added
- Installable Python package (`pip install parrotia`) using a `src/` layout.
- `parrotia` console command (headless CLI) and `parrotia-gui` GUI launcher,
  registered as entry points.
- `python -m parrotia` runs the CLI; `python -m parrotia.app` runs the GUI.
- Public API surface re-exported from the top-level `parrotia` package
  (`Transcriber`, `WRITERS`, model/format constants, result dataclasses).
- `parrotia[cuda]` optional dependency group for NVIDIA GPU acceleration.
- GitHub Actions release workflow that builds the sdist + wheel and publishes a
  GitHub Release on every `v*` tag.

### Changed
- Source modules moved under the `parrotia` package; imports are now
  package-relative.
- Launchers (`run.bat`, `run.sh`) updated to run the package from source.
